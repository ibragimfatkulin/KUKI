# KUKI

Кулинарный помощник, который собирает блюдо из продуктов, уже лежащих дома, и не предлагает сковороду, если на кухне только микроволновка.

## Стек

Next.js, React, TypeScript, Tailwind CSS, shadcn-совместимые компоненты, Lucide, Prisma, SQLite, Zod. AI вызывается на сервере через совместимый Chat Completions API.

## Запуск

Нужен Node.js 20+.

```powershell
cd "C:\Users\user\Desktop\VS Code\chef ai"
copy .env.example .env
npm install
npx prisma generate
npx prisma db push
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).

Проверки:

```powershell
npm test
npx tsc --noEmit
```

## Подключение AI

В `.env`:

```
OPENAI_API_KEY="sk-..."
OPENAI_BASE_URL="https://api.openai.com/v1"
OPENAI_MODEL="gpt-4o-mini"
```

Ключ не попадает в браузер: его читает только серверный код. Подойдёт любой сервис с тем же путём `/chat/completions`. Пустой ключ не ломает приложение: рецепт собирает локальный модуль и помечает это на карточке. Ответ модели принимается только как JSON и дополнительно проверяется на технику, диету и испорченные продукты.

## Что уже работает

- Ввод продуктов по одному, списком, через Enter и обычной фразой.
- Количество и единицы, правка и удаление, подсказки.
- Несколько видов техники, включая режим без нагрева.
- Время, порции, тип блюда, сложность, цель, диеты и аллергены.
- Отдельный список продуктов, которые можно докупить.
- Генерация рецепта, шаги, ориентировочные калории и БЖУ.
- Пометка продуктов, которых нет дома, и доли своих продуктов.
- Отказ готовить из просроченного, старого или пахнущего продукта.
- Режим готовки: один шаг, назад/дальше, прогресс, таймер и пауза.
- История, избранное, ссылка на рецепт.
- Гостевой профиль и схема пользователя под будущий вход.
- Примеры на пустых экранах.

## Ограничения

- Питательность ориентировочная, особенно если вес не указан.
- Локальный модуль собирает домашнее блюдо по правилам кухни, но не заменяет большую модель, когда ключ задан и ответ прошёл проверки.
- Фотографии общие для типа блюда, а не сгенерированы под конкретный рецепт.
- Входа по почте ещё нет: данные живут в этом браузере.
- Светлая тёплая тема из спецификации. Тёмная тема не включена.
