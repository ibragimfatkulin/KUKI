# KUKI — техническая спецификация

## Продукт

Веб-приложение собирает ужин из продуктов, которые уже есть дома. Пользователь передаёт ингредиенты, технику и ограничения. Сервер возвращает структурированный рецепт, сохраняет его и открывает карточку с режимом готовки.

## Архитектура

- Frontend: Next.js App Router, React, TypeScript, Tailwind CSS, компоненты в стиле shadcn/ui, Lucide.
- Backend: Route Handlers в `src/app/api`.
- База: SQLite + Prisma. Схема готова к замене URL на PostgreSQL.
- AI: серверный вызов Chat Completions. Ключ читается только из окружения. Если ключа нет или ответ не проходит проверку, рецепт собирает локальный модуль с теми же ограничениями.

Гость создаётся при первом запросе. Идентификатор лежит в httpOnly-cookie `fridge_uid`. Поля `User.email` и `User.passwordHash` оставлены для будущего входа.

## Контракт генерации

`POST /api/recipes/generate`

Вход: продукты, техника, время (10/20/30/45/60), порции 1–8, тип блюда, сложность, цель, диеты, аллергены, отдельный список «могу докупить».

Выход: рецепт с названием, описанием, шагами, КБЖУ на порцию, пометками «дома» / «докупить», процентом использования своих продуктов и предположениями о весе.

Модель обязана вернуть JSON. Ответ сверяется с Zod, количества пользователя восстанавливаются, шаги проверяются на запрещённую технику. Сырое мясо, птица, рыба и яйца не попадают в холодный рецепт. Просроченные и испорченные продукты останавливают генерацию.

## Данные

- `User` — гость или будущий аккаунт.
- `Recipe` — карточка, шаги в `instructions` (JSON), техника и исходный запрос.
- `Ingredient` — строка рецепта, `isAvailable = false` означает докупить.
- `Favorite` — связь пользователя и рецепта.
- `GenerationHistory` — снимок запроса и ссылка на рецепт.

## Основные маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET/POST | `/api/session` | Гостевой профиль и счётчики |
| POST | `/api/recipes/generate` | Новый рецепт |
| POST | `/api/recipes/examples` | Сохранить пример |
| GET | `/api/recipes/:id` | Карточка, в том числе по ссылке |
| GET/POST | `/api/favorites` | Список и сохранение |
| DELETE | `/api/favorites/:recipeId` | Убрать из избранного |
| GET | `/api/history` | История |
| DELETE | `/api/history/:id` | Удалить запись |
| POST | `/api/ingredients/parse` | Разобрать фразу в продукты |
